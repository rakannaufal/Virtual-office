# Lisensi aset RN GROUP

Karakter chibi aktif, rig, animasi, furnitur, dan tekstur canvas dibuat dalam source proyek ini. Foto referensi pengguna tidak disalin menjadi aset publik. Tidak ada biaya atau unduhan model saat menjalankan tampilan chibi.

Aset GLB lama yang tetap disimpan di public/models bersumber dari Quaternius Ultimate Modular Characters / Ultimate Modular Women, CC0 1.0. Konversi GLB distribusi Ducz.CharacterCreator.

- https://quaternius.com/packs/ultimatemodularcharacters.html
- https://quaternius.com/packs/ultimatemodularwomen.html
- https://github.com/LuanDucate/Ducz.CharacterCreator/tree/main/public/models
- https://creativecommons.org/publicdomain/zero/1.0/

File: male-suit.glb (Male/Suit), male-casual.glb (Male/Casual_2), male-worker.glb (Male/Worker), female-suit.glb (Female/Suit), female-formal.glb (Female/Formal), female-casual.glb (Female/Casual).

Salinan keterangan lisensi asli ada di public/models/LICENSE-Quaternius.txt. Hanya aset model yang diambil; source/executable proyek tersebut tidak dijalankan atau disertakan.

Furnitur, lantai, tanaman, dekorasi, tekstur monitor, dan papan nama dibuat melalui source Three.js dalam paket ini. Ikon: Lucide, lisensi ISC. Vue/Pinia/Vite/Three.js/Supabase/JSZip memiliki lisensi masing-masing pada dependensi.
